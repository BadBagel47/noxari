# Noxari development guidance

## Handover and user workflow

Read `HANDOVER.md` at the start of a new session alongside this file and `README.md`. It records user decisions, current status, pending approval and the Guided Finder, the full-viewport workspace and current approval state. Recommend a model before each new development step and wait for the user's explicit approval; allow them to bundle changes before a run. Do not treat a roadmap entry as approval to implement it.

Keep `HANDOVER.md` current after each completed development step, relevant fix, user validation or change of plans/workflow. Record the verified app commit, test/deployment evidence, limitations, remaining work and approval state. Keep README and this file consistent; do not store secrets, private coordinates or full chat logs in the handover.
