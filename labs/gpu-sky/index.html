Noxari · separat GPU-prototyp

Jämför ritningen av stjärnor och Vintergatan. Ordinarie appens horisontvy använder också dessa GPU-lager när de stöds. Dra för att titta runt, nyp för zoom.

Laddar lokala stjärndata…

Jämförelsen kör Canvas → GPU → GPU → Canvas med samma natt, vy, linjer och fasta rörelseupplösning. Tider avser webbläsarens bildruteloop och ritkommandon, inte garanterad visad FPS. Efter jämförelsen återställs ditt tidigare ritläge. Välj GPU för manuell provning. Rapporten stannar här tills du väljer att spara den. Inga GPS- eller telefonbehörigheter begärs.
